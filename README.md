# MAN VS. DOOR — company website

Marketing site for MAN VS. DOOR (formerly We Fix Garage Doors), a residential and commercial garage door service company in Southwest Ohio. *"We haven't lost yet."*

**Live:** https://wefixdoors.pro

## Highlights
- Fast static site with live Google reviews
- Embedded instant-quote tool (see WFGD-QuoteBooking-public)
- Every change deploys to a protected beta site first; going live is a deliberate one-click step

HTML · CSS · JavaScript · PHP · GitHub Actions
